# 数字电路图编辑器

一个基于 **D3.js + SVG + 原生 HTML/CSS/JavaScript**
开发的数字电路图编辑器项目。

项目当前以 HTML
版本作为主开发版本，目标是逐步实现一个可视化、可编辑、可保存的数字电路设计工具。未来计划在保持核心数据模型和交互逻辑基本一致的前提下，继续开发
**Vue** 和 **React** 版本。

## 项目定位

本项目不是单纯的电路图展示页面，而是一个逐步完善中的可视化数字电路编辑器。

当前重点包括：

-   元件库
-   拖拽放置元件
-   元件移动
-   引脚连接
-   连线编辑
-   元件与连线属性编辑
-   选中状态管理
-   删除操作
-   画布缩放与平移
-   JSON 数据导入 / 导出
-   一键清空画布

后续可以继续扩展：

-   撤销 / 重做
-   复制 / 粘贴
-   多选
-   元件旋转
-   网格吸附
-   总线
-   标签
-   更完善的连线布线
-   数字逻辑仿真
-   真值状态显示
-   时钟与时序仿真
-   电路文件管理
-   Vue 版本
-   React 版本

> 当前版本主要定位为"电路图编辑器"，现有元件库中的数字逻辑元件主要完成图形化编辑与连线能力，并不代表已经完整实现真实逻辑仿真。

## 2. 拖拽创建元件

可以从左侧元件库拖拽元件到画布。

元件放置时会根据网格进行位置对齐，使电路图更容易保持整齐。

------------------------------------------------------------------------

## 3. 元件移动

画布中的元件可以直接拖动。

移动元件时，与其连接的连线会同步更新。

------------------------------------------------------------------------

## 4. 引脚连线

通过点击引脚完成连线：

``` text
点击起始引脚
      ↓
进入连线状态
      ↓
点击目标引脚
      ↓
创建 Wire
```

同时支持取消连线：

-   右键取消
-   ESC 取消
-   点击画布空白区域取消
-   再次点击当前引脚取消

------------------------------------------------------------------------

## 5. 连线编辑

连线支持：

-   点击选中
-   选中高亮
-   修改颜色
-   修改宽度
-   删除
-   右键删除

为了提高连线操作的容错率，连线除了实际显示线条外，还可以使用更宽的透明命中区域，使用户更容易点击到细线。

------------------------------------------------------------------------

## 6. 元件属性编辑

点击画布中的元件后，可以打开属性面板。

目前主要支持：

-   修改元件颜色
-   删除元件

属性修改采用"确认提交"的方式。

也就是说：

``` text
修改属性
   ↓
暂存为 Draft
   ↓
点击「确认修改」
   ↓
写入元件数据
   ↓
重新渲染
```

如果没有点击确认，则不会真正修改电路数据。

------------------------------------------------------------------------

## 7. 连线属性编辑

点击连线后，可以编辑：

-   连线颜色
-   连线宽度

宽度当前支持有限范围的数值调整。

同样采用确认提交机制。

------------------------------------------------------------------------

## 8. 删除

支持多种删除方式：

-   属性面板中的删除
-   Delete
-   Backspace
-   右键删除连线

删除元件时，后续可以进一步完善为自动删除与该元件相关的全部连线。

------------------------------------------------------------------------

## 9. 画布缩放与平移

编辑器使用 D3.js Zoom 实现画布交互。

支持：

-   滚轮缩放
-   画布平移
-   缩放范围限制

元件和连线统一位于 SVG 的缩放坐标系中。

------------------------------------------------------------------------

## 10. JSON 导入 / 导出

项目支持将当前电路保存为 JSON。

JSON 主要保存：

``` text
components
├─ id
├─ type
├─ x
├─ y
└─ color

wires
├─ id
├─ color
├─ width
├─ from
└─ to
```

同时包含：

``` text
format
version
exportedAt
nextId
```

因此 JSON 文件不仅用于保存，也可以作为未来 Vue / React
版本共享的数据格式基础。

------------------------------------------------------------------------

## 11. 清空画布

提供"一键清空画布"功能。

执行前会显示确认提示，并显示当前：

-   元件数量
-   连线数量

确认后：

-   删除所有元件
-   删除所有连线
-   清除当前选中状态
-   取消正在进行的连线
-   重置 ID

# 技术架构

当前 HTML 版本采用比较简单的编辑器架构：

``` text
用户操作
   │
   ├── 拖拽元件
   ├── 点击引脚
   ├── 点击元件
   ├── 点击连线
   ├── 修改属性
   └── 键盘 / 鼠标操作
          │
          ▼
      数据模型
          │
     ┌────┴────┐
     ▼         ▼
components   wires
     │         │
     └────┬────┘
          ▼
       SVG 渲染
          │
          ▼
       D3.js
```

核心数据结构可以概括为：

``` js
components = [
  {
    id,
    type,
    x,
    y,
    color
  }
];

wires = [
  {
    id,
    color,
    width,
    from: {
      compId,
      pinIndex
    },
    to: {
      compId,
      pinIndex
    }
  }
];
```

# 三个版本之间的关系

未来三个版本建议共享同一套"核心数据格式"，而不是共享具体 UI 实现。

``` text
                 ┌──────────────┐
                 │ Circuit Data │
                 │ JSON Schema  │
                 └──────┬───────┘
                        │
          ┌─────────────┼─────────────┐
          ▼             ▼             ▼
       HTML/D3         Vue          React
```

这样可以保证：

-   HTML 创建的电路可以被 Vue 读取
-   Vue 创建的电路可以被 React 读取
-   React 创建的电路可以导出后由 HTML 读取
-   三个版本共享统一的数据文件格式

因此，后续开发 Vue / React 版本时，建议优先保持以下内容统一：

1.  元件 type
2.  元件 ID
3.  元件位置
4.  Pin 定义
5.  Wire 连接关系
6.  元件属性
7.  连线属性
8.  JSON Schema

# 当前版本定位

当前项目仍属于持续开发中的编辑器原型。

目前最重要的不是一次性完成所有功能，而是逐步建立：

``` text
编辑器 UI
    ↓
统一数据模型
    ↓
稳定的交互系统
    ↓
JSON 数据格式
    ↓
数字逻辑仿真
    ↓
Vue / React 多端实现
```

其中 **JSON 数据模型** 是后续 HTML、Vue、React 三个版本之间的重要桥梁。
